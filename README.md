# Soltech Electrical — Website

Professional website for **Soltech Electrical**, a licensed electrical and solar company based in Nairobi, Kenya.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Homepage — hero, services overview, why us, testimonials |
| `about.html` | About the company, team, values |
| `services.html` | Full services detail page |
| `cctv.html` | CCTV installation dedicated page |
| `gallery.html` | Project gallery with filter |
| `contact.html` | Contact & quote request forms |
| `shared.css` | Global styles, navbar, footer, buttons |
| `main.js` | Navbar scroll, mobile menu, hero slideshow, animations |

## Features

- ✅ Fully responsive — mobile, tablet, desktop
- ✅ Working hamburger mobile navigation
- ✅ Hero slideshow with auto-advance
- ✅ Scroll reveal animations
- ✅ Counter animation on stats
- ✅ Testimonials slider
- ✅ Gallery filter by category
- ✅ Responsive contact & quote forms
- ✅ Floating WhatsApp button
- ✅ Google Maps embed
- ✅ M-Pesa payment callouts

## Deployment (GitHub Pages)

1. Push to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, root folder
4. Site will be live at `https://yourusername.github.io/repo-name/`

## Contact Integration

Forms use [Formspree](https://formspree.io) — replace `YOUR_FORM_ID` and `YOUR_MESSAGE_FORM_ID` in `contact.html` with your actual Formspree endpoint IDs.

## Tech Stack

- Plain HTML5, CSS3, Vanilla JS — no build tools, no frameworks
- Google Fonts: Bebas Neue + DM Sans
- Unsplash for photography (replace with actual project photos when available)
- Formspree for form handling
