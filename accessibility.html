Accessibility Statement

Last updated: to be confirmed at publication · Draft pending review by counsel

This is a draft. It describes the accessibility work already built into the site's templates, but the site has not yet had a formal accessibility audit.

On this page

  1. Our commitment
  2. Standard we aim for
  3. Accessibility features on this site
  4. Known issues
  5. Feedback and contact

1. Our commitment

External Excellencies Global Foundation wants this website — including our Impact archive of community projects — to be usable by as many people as possible, including people who use screen readers, keyboard navigation, or browser zoom.

2. Standard we aim for

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. This site has not yet undergone a formal accessibility audit, so this should be treated as a goal we are working toward rather than a certification.

3. Accessibility features on this site

  • A "Skip to content" link at the top of every page for keyboard and screen-reader users
  • A labelled primary navigation menu with visible focus states
  • aria-expanded attributes on dropdown and mobile-menu toggles
  • Respect for the operating system's "reduce motion" setting, including on the animated statistics on our Impact page
  • Text that resizes with browser zoom without breaking layout

4. Known issues

We are aware of gaps that still need work, including: photograph placeholders across the site that need real alt text once real photographs are added; some historical project entries that are text-only pending verified images; and a full manual screen-reader pass that has not yet been carried out. This section will be updated as these are addressed.

5. Feedback and contact

If you have trouble using any part of this site, please tell us. Include the page you were on and, if possible, the browser or assistive technology you were using, via our Contact page. We will do our best to fix genuine barriers and to respond to you directly.
